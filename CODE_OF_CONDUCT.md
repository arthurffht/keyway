# Code of Conduct

Keyway follows the [GNOME Code of Conduct](https://conduct.gnome.org/).

It applies to every project space: the repository, issues, pull requests and Discussions.
To report a problem, contact the maintainer privately through the e-mail address on the
[maintainer's GitHub profile](https://github.com/arthurffht), or use GitHub's
[reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
